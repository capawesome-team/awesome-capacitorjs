# Contribution Guidelines

Thanks for your interest in contributing to Awesome Capacitor!

Please ensure your pull request follows the guidelines below.

## Adding an entry

- Make sure the entry is related to Capacitor.
- Add one entry per pull request when possible, so it can be reviewed quickly.
- Add the entry to the section it belongs to, keeping the existing ordering of that section.
- Use the following format: `- [name](link) - Description.`
- Keep descriptions short, factual, and on a single line.
- Start the description with a capital letter and end it with a period.
- Link to the project's documentation or repository, not to a redirect or a tracking link.
- Do not add marketing copy, badges, or emoji to descriptions.

## Quality standards

Entries should be actively maintained and usable. A pull request may be rejected if the project:

- Is archived, deprecated, or has been abandoned.
- Has no documentation or README.
- Duplicates an existing entry without adding value.

## Removing an entry

Removals are welcome too. If a listed project is archived, deprecated, or broken, open a pull request that removes it and mention why in the description.

## Before you submit

- Check that your links resolve and do not return a 404.
- Check that the entry is not already listed.
- Update the table of contents if you added a new section.

Thanks again for helping keep this list useful!
